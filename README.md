# Дозиметр на микроконтроллере CH32L103

## Принцип работы

### Режим дежурного измерения

В режиме дежурного измерения, микроконтроллер (МК) переведен в режим SLEEP (RM p10) с режимом пробуждения от внутренних событий WFI, в нем ядро находится в спящем режиме, работает только активированная периферия.  ШИМ выполнен на таймере TIM4 CH1 включен постоянно и управляет затвором транзистора преобразователя напряжения. От таймера TIM МК каждые 10мс выходит в пробуждение, активирует АЦП производится цикл измерения выходного значения преобразователя через вход ADC N8 и корректируется значение  расстояния между импульсами ШИМ, для получения необходимого напряжения с учетом температуры, после чего МК снова переходит в SLEEP. Температура измеряется периодически (не с каждым пробуждением) с внутреннего датчика МК. Также активирован ОУ и компаратор, которые фиксируют импульсы с датчика радиации. При зафиксированном всплеске напяжения с датчика на выходе компаратора инициируется прерывание, которое пробуждает МК из состояния SLEEP, наращивает значение радиации и снова переводит МК в SLEEP.

### Режим работы с USB

МК поддерживает работу с USB CDC драйвером (эмуляция COM порта через USB). При подключении USB шнура к прибору, на порте PA10 МК (режим входа с внутренней подтяжкой вниз) устанавливается высокий уровень,  прибор выходит из режима SLEEP и активирует CDC драйвер, для обмена данными.
